### 功能

- 每日自动打卡
- 每日自动签到。
- 第三方页面自动签到
- 会员日助力，当存在多个账号时，默认助力第一个账号

### 使用教程
- 使用`Script-Hub`将脚本转化为相应代理软件格式
- 打开小程序，进入早起打卡页面获取`Cookie`
- 添加`task`定时任务，cron可设置为`30 8,17 * * *`
